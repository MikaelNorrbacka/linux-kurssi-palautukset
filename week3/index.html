What commands did I use?

  • date '+%Y-%m-%d %H:%M:%S' displays the current date, time and time zone.
  • uptime -p displays how long the server has been running.
  • df -P / | awk 'NR==2 {print }' extracts the root filesystem usage percentage.
  • free -m displays memory information in mebibytes.

How the script works

It collects information using Linux commands and stores the results in Bash variables. An if statement checks whether root disk usage is at least 80% to set WARNING or OK.

The script writes to a temporary file first and moves it into place as index.html. Nginx serves this file at /viikko3/.

Scheduling

A cron job runs the script once every minute so the status page stays current automatically.
